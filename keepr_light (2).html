How to use Keepr

Daily use

  • Load photo — load a photo into a slot. Drag it onto the grey area or click the button.
  • Place label — click to enter place mode (teal outline appears around photo), then click anywhere on the photo to drop a pin manually. Click the button again to exit.
  • Export — saves this photo as a JPEG with all numbered labels burned in. Good for printing.
  • Edit any item name in the table — the pin on the photo updates instantly. Drag a pin to reposition it. Drag ⠿ to reorder rows.

Voting

  • Click ✓ or ✕ for each item. Click again to clear. The Final column auto-calculates by majority.
  • Click a Final pill to type a custom decision (e.g. "Donate"). Click ↺ to revert to auto.
  • Pin colours: teal = pending · green = keep · red = discard · amber = tie.

Saving & sharing

  • Save backup — downloads a .json file with everything: items, votes, notes, photos. Do this after a voting session. The amber dot next to the button means you have unsaved changes.
  • Load backup — restores from a .json file. Use this to pick up where someone else left off.
  • Export CSV — spreadsheet of all items and votes. Open in Excel or Google Sheets.
  • Share file — exports a standalone .html file with everything baked in. Send to anyone — they open it in a browser, no setup needed.
  • If the green dot shows Live sync, votes update in real time for everyone who has the file open.

Getting an update from the developer

  • When a new version of Keepr is ready, you'll receive a new .html file.
  • Before updating: click Save backup to download your .json data file.
  • Go to your Netlify project page → Production deploys → click browse to upload → select the new .html file. Your URL stays the same.
  • Once updated, click Load backup and select your saved .json file to restore all your data.

Troubleshooting

  • No green dot / not syncing — click ⚙ Firebase and hit Connect. Check your internet connection.
  • Photos blank after sharing — each person loads their own photos once. Label positions sync automatically.
  • Auto-label not working — check the API key field in the top bar starts with sk-ant-.
  • Something broken — save a backup, reload the page. If still broken, load the backup to restore your data.
